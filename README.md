# cifras-dados

Repertório do app **Cifras** — https://gianzortea.github.io/cifras/

Este repositório é o "online" do app: não tem código, só os dados que o app
envia e baixa.

- `cifras.json` — músicas, eventos e a lista de faixas (o mesmo formato do
  exportar/importar do app)
- `audio/` — um arquivo por faixa de áudio

## Para baixar o repertório (banda)

No app: **Ajustes → Online (GitHub) → ligar → Baixar do GitHub**.
Não precisa de conta nem de token. Depois de baixar, funciona sem internet.

## Para enviar (quem mantém o repertório)

Em Ajustes, cole um token do GitHub com acesso só a este repositório e
permissão *Contents: Read and write*, e toque em **Enviar para o GitHub**.

Não edite os arquivos daqui à mão: o app reescreve o `cifras.json` a cada envio.
